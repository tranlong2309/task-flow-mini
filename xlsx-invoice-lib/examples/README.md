# Examples

The runnable `Example.java` demonstrates file-to-file processing. The sample workbooks are generated by the test fixture utility in the project build so the examples stay aligned with the documented contract.

Run from this project after building:

```text
java -cp target/xlsx-invoice-lib-1.0.0.jar;... Example
```

The consumer projects under `consumer-maven` and `consumer-gradle` demonstrate dependency consumption without Spring.
